In traditional computer vision web applications, user images travel to a remote cloud server for processing. ColonyVision Lab flips that paradigm: your browser compiles OpenCV C++ directly to WebAssembly (Wasm) inside an isolated Web Worker, persists rich multi-megabyte image Blobs in IndexedDB, and executes quantitative microbiology morphometry with zero server round-trips.

The Browser Is the Computer: As Dr. Ernesto Lee emphasizes in CAI 2840, modern client browsers possess Muscle (WebAssembly), Memory (IndexedDB), and Eyes (OpenCV.js). Your pixels don't need a round-trip ticket across the internet to be understood.
Stage 1

Zero-Copy Image Ingestion & Web Worker Dispatch

High-resolution photos from modern smartphones can reach 12 to 48 megapixels. Transporting such massive pixel arrays across threads can freeze user interfaces.

ColonyVision utilizes the browser's native createImageBitmap() API to decode image streams asynchronously. The bitmap is then transferred to our dedicated Web Worker via worker.postMessage({ bitmap }, [bitmap]). By passing the bitmap in the transfer list, ownership is transferred with zero memory copies.

Stage 2

Petri Dish ROI Detection & Rim Masking

Biological Petri dishes have circular plastic rims that cause optical glare, reflections, and meniscus distortions.

The pipeline first downscales a working copy to 400px and executes Canny edge detection (cv.Canny(blur, edges, 30, 90)). Circular contour candidates are evaluated using enclosing circle circularity ratio. Once the 90mm dish center and radius are established, an internal circular mask is constructed. Pixels outside the growth surface are masked to zero, eliminating rim glare artifacts.

Stage 3

Multi-Color Space Segmentation & Adaptive Thresholding

Microbiology uses diverse growth media: light amber Nutrient Agar, opaque dark-red Blood Agar, and translucent Hemocytometer microscope grids.

ColonyVision converts the image into both Grayscale (cv.COLOR_RGBA2GRAY) and HSV (cv.COLOR_RGB2HSV) color spaces. On Blood Agar, yellow S. aureus colonies stand out dramatically in the Value (V) channel. On Nutrient Agar, an Adaptive Gaussian Threshold (cv.adaptiveThreshold) dynamically computes local neighborhood thresholds to compensate for non-uniform lighting across the dish.

Stage 4

Morphological Opening & Distance Transform Separation

Raw binary thresholds suffer from two challenges: tiny single-pixel camera noise, and clustered colonies that touch each other.

We apply Morphological Opening (cv.morphologyEx) with an elliptical 3×3 structuring element. This erodes stray noise specks and dilates the remaining authentic colony bodies. For touching colonies, a Euclidean Distance Transform (cv.distanceTransform) computes the distance from each pixel to the nearest background pixel, isolating the centroid peaks of contiguous colonies.

Stage 5

Contour Extraction & Biometric Morphometry

Colonies are vectorized via cv.findContours(cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE). Each candidate contour undergoes rigorous morphological analysis:

  • Surface Area (A): Computed via Green's theorem contour area integration (cv.contourArea).
  • Boundary Perimeter (P): Closed contour arc length (cv.arcLength).
  • Centroid Localization: Derived from spatial moments \( (m_{10}/m_{00}, m_{01}/m_{00}) \).
  • Size Classification: Categorized into Punctiform (< 0.5mm), Small (0.5 – 1.5mm), Medium (1.5 – 3.0mm), and Large (> 3.0mm).
Shape Analysis
Circularity (C) = 4π × Area Perimeter2
Also known as the isoperimetric quotient. Spherical, uniform colonies yield a circularity score C ≈ 1.0. Irregular smudges, scratches, or uneven agar lines yield values below 0.40 and are automatically filtered out.
Concentration Assay
CFU / mL = Total Count (CFU) Plated Volume (mL) × 1 10Dilution
Computes viable colony concentration in the stock suspension based on serial dilution powers of 10.
Stage 6

Wasm Memory Safety & IndexedDB Structured Persistence

Because OpenCV.js compiles C++ into WebAssembly, objects allocated via Emscripten live in a dedicated heap. JavaScript garbage collection does not automatically free cv.Mat allocations.

ColonyVision implements a strict Mat Tracker pattern: all intermediate matrices are tracked and systematically deleted inside a try ... finally block via T.free().

Completed assays are stored in the browser's IndexedDB database (colonyvision_db), persisting high-resolution PNG Blobs, thumbnail previews, and JSON colony metrics across browser restarts and offline sessions.
